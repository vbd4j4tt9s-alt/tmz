Tests: `sh docs/proposals/R154/tests/run_fixes.sh <scratch> [mutate]` (`test_popups154.luau` section 5, 227 checks; `mutate154.py` 36 breakages, all caught). `Config.Version` is unchanged; no server rule, remote, odds or manifest entry changed; BackgroundMusic untouched; line 1 of every client script is still the load guard.

## Before
R154 sized the popup field in pixel offsets: the same on screen at every camera distance. Zoom out and the runner shrinks but the numbers do not, so they look bigger next to him.

## Now (world-consistent, `SpeedPopupStyle.Zoom`)
| | |
|---|---|
| Default camera distance | **12.5 studs** (Roblox's default; nothing in the game sets it: the place's StarterPlayer has Roblox's 0.5 / 128, `GiantVisualSafety` caps zoom-out at 100). Here the popups are exactly R154: 35 px text, 32 px bolt, 240 x 58 box at 1080 p |
| Zoomed out | scale = 12.5 / distance: 25 studs = half (17.5 px text), 50 = a quarter |
| Fade / hidden | text 14 px at **31.25 studs**, fading linearly to 12 px at **36.46 studs** (12.5 x 35 / 12), gone (container hidden) past that |
| Close up | the same law, **capped at 1.3x** (45.5 px text) from 9.6 studs inward; first person (0.5 studs or less) is the same 1.3x, never a giant popup |
| Phones | the cutoff is by scale, not by pixels: a 0.8x phone unit shows 9.6 px text at the cutoff |

The three numbers (12.5, 1.3, 14 / 12) are `S.Zoom` in `SpeedPopupStyle`; `S.ZoomScale(distance)` returns scale and fade (pure, no allocation).

## How (and why this way)
* `SpeedGainPopup`: each pooled field (the BillboardGui, still pixel-sized, always on top, on the root at head height) gets one container `Frame` ("Zoom", centred, filling it) holding all popup frames, with **one `UIScale`**. The existing per-frame step measures the camera's distance to the field's anchor (root + head offset, as the field already is), asks `ZoomScale`, and writes the container's scale **only when it moved by more than 0.004** (0.14 px of a 35 px text): at most one property write a frame, none while the camera rests. The shown / hidden flip is one more write when the cutoff is crossed. The popups' own scale (unit x pop-in), position, tilt, text, ZIndex, caps, pool, retire fade, Reduced Motion, phone fan are untouched: a popup is a thing inside a scaled container, so its size relative to the runner is constant and a zoom change moves only the container.
* The fade multiplies each popup's alpha by the field's fade through the existing alpha cache (writes only while the camera is inside the 5-stud fade band and moving). A hidden field is not moved at all (its popups still live and die on their clock, nothing is cut short; the first frame it shows again writes the whole pose).
* The field is 1000 x 792 (was 768 x 608, x 1.3) so the biggest fan at the cap still fits the billboard whether or not it clips.
* Chosen over BillboardGui world-scale sizing (`Size` in scale = studs): the whole fan, text and outlines are designed in pixels, and how a studs-sized billboard maps those pixel offsets is not something I can measure here; it also has no way to cap the close-up or to fade, and R154's 35 px at 12.5 studs would have to be re-derived. The UIScale keeps every R154 number as it was and is exact at the default zoom. Distance is the Euclidean distance (not depth along the look vector): it only changes when the camera zooms or the runner moves, not when the camera turns, so the size does not breathe while looking around.
* Other BillboardGuis and other popups (treadmill bonus, keeper labels, name tags) are not touched: the script only writes to its own fields (tested with a name tag next to a moving camera).

## Not measurable here
The engine's own UIScale-in-BillboardGui rendering (a UIScale on a frame scales it and its descendants about the frame's anchor point; the frame is centred, so about the head) and the camera's real zoom distance (the focus is the root + 1.5 studs, the field's anchor is within about 0.1 stud of it). If the owner wants the cutoff farther or nearer it is `S.Zoom.HideText` (12) / `FadeText` (14): hide at 12.5 x 35 / HideText studs.
