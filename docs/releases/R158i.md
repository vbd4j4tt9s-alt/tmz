# R158i: the tutorial's free bonus roll always arrives; new players start at 20,000 speed (shown as 1)

Needs **R158h installed** (`Config.Version` reads `'V150 R158h'`). **One installer:** `installers/R158i_install.lua` (~59 KB, 14 scripts,
one new module `SpeedDisplay`). Edit mode, Play stopped, **close every script tab first**, paste ALL of it into the Command Bar, Enter,
wait for **`[R158i] Installed.`**, then **Save** and start a **new** Play session. `Config.Version` reads `'V150 R158i'` after it.

Undo: `require(game.ServerStorage.ChestChase_R158i_Backup.Installer)("undo")`. Profile version stays 22.

## What changed
- **The free tutorial bonus roll:** why it didn't come: new players already held the 2 rolls from the Verity gift (the most you can hold
  ready), so the free roll added nothing; and the game asked for it only once, so a busy moment lost it. Now the server gives it the
  moment you reach the last step, with no ask. If you already hold 2, it waits and becomes ready as soon as you use one (3 rolls in all).
  Once per player.
- **Speed:** every new player starts at **20,000 speed**; existing players under 20,000 are raised to 20,000. On screen, every speed
  number shows **20,000 less (plus 1), never below 1**: your speed, the player list, the TOP SPEED board, the keepers' SPEED NEEDED signs and
  the hub gate keys. So a new player sees **1**; a keeper that needs 50,000 shows 30,001. The game still runs on the real numbers; the +60
  popups are gains and are unchanged. `/test stats` and `/test speed` show both (e.g. "61 (20,060 points)").

`Config.Version = 'V150 R158i'`.
