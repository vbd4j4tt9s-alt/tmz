# R118: scrollable top-100 leaderboards

Needs R117 installed first (refuses otherwise, changing nothing). Installer: `installers/R118_install.lua` (~39 KB).
Edit mode, Play stopped, paste ALL of it into the Command Bar, Enter, then **Save** and start a **new** Play session.

Undo: `require(game.ServerStorage.ChestChase_R118_Backup.Installer)("undo")` (undo R118 before R117).

## What changed (3 scripts, 1 new)

- **Scroll to #100:** the hub's TOP SPEED and MOST MONEY boards now hold the global top 100 (was 25). A sign in the world
  cannot be scrolled in Roblox, so each player now gets their own copy of the board drawn on the same sign
  (`StarterPlayerScripts.LeaderboardClient`): mouse wheel or touch-drag scrolls it.
- **Polish:** green header with the title and "GLOBAL TOP 100 • UPDATED N MIN AGO"; gold/silver/bronze rows with medals
  for the top 3; striped rows with round avatars and rank badges; **your own row highlighted** ("⭐ YOU"); a footer with
  **YOUR RANK #N** (or "Not in the top 100 yet - keep going!") and a **FIND ME / TOP** button that scrolls there.
- **Cheap:** only the ~12 rows on screen exist and are reused while scrolling.
- **Server** (`SpeedBoardService`): fetches the top 100 for both boards and publishes them on the board model. Exact
  speed reads only for the top 10 and only when their score changed (stays inside the DataStore read budget); the rest
  use the sorted value (exact to ~9 digits, more than the board shows). The server's own sign keeps a top-10 fallback.
- `Config.Version = 'V149 R118'`.

## Test in Studio

- [ ] Walk to the hub boards: they look new, scroll with the mouse wheel (PC) and drag (phone emulator) down to #100.
- [ ] Your row is highlighted and FIND ME jumps to it. (In Studio the boards use separate _Studio stores, so they may
      only show you.)
