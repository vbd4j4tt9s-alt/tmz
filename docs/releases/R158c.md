# R158c: the free Void Pack needs the tutorial (no 20-minute wait), and the tutorial can't be replayed

Needs **R158b installed** (`Config.Version` reads `'V150 R158b'`). **One installer:** `installers/R158c_install.lua` (~47 KB, 8 scripts,
nothing moved or deleted). Edit mode, Play stopped, **close every script tab first**, paste ALL of it into the Command Bar, Enter, wait for
**`[R158c] Installed.`**, then **Save** and start a **new** Play session. `Config.Version` reads `'V150 R158c'` after it.

Undo: `require(game.ServerStorage.ChestChase_R158c_Backup.Installer)("undo")`. No saved-data change.

## What changed
- **Free Void Pack:** no more 20-minute wait. You only need to **finish the tutorial** (skipping it counts the same as finishing it, like
  everywhere else in the game). Until then the pedestal says "finish the tutorial to claim", Hold E is off, and a try says "finish the
  tutorial to get your free void pack!". **Still one pack per player:** once you have it, the pedestal shows "CLAIMED ✓" for you.
- **No replaying the tutorial:** the "Replay tutorial" button is gone from Settings (no empty gap), and the server refuses a replay too,
  so a finished player stays finished.

`Config.Version = 'V150 R158c'`.

## Test in Studio
- A new player (or `/test` a fresh profile): the pedestal says "finish the tutorial to claim". Finish or skip the tutorial: Hold E works
  at once. Claim: "CLAIMED ✓"; a second try is refused.
- Settings: no "Replay tutorial" button.
