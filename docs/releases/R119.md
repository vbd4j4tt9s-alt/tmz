Edit mode, Play stopped, paste ALL of it into the Command Bar, Enter, then **Save** and start a **new** Play session.

## What changed (10 scripts)

- **Fruit bonuses multiply** (`BalanceRules`, `WeatherTraits`): size x (the fruit's size, never below x1),
  Gold x3 / Diamond x6, Drippy x2 / Frosted x3 / Charged x5 (stacked weathers multiply), all multiplied together,
  capped at x100. Average fruit now sells for ~17% more (was ~2%). Sell menu shows "Bonus ×N (size × coat × weather)".
- **Late prices x1.2** to keep the 200-hour target (`EconomyBalance90`): Machine 6 6.1T, Machine 7 180T, Aurora 144B,
  Nebula 156T, Royal 204T, Crystal boots 1.8T, Thunder boots 156T, Fence 6 1.56T, Fence 7 72T.
  Simulated active player: Thunder boots ~79 h, Machine 7 ~156 h, Royal ~202 h.
- **Trail head pieces** (client-side, welded to the head, shop previews too): Aurora halo, Nebula space dust with
  twinkling stars, Royal glowing gold crown with jewels. Same budget rules as the trail effects; hidden in first person.
- **Treadmills:** names removed; console shows only the tier pips, plaque only the numeral.
- `Config.Version = 'V149 R119'`.
