# R110: tutorial, bigger HUD, no more tripping, smooth keepers

Installer: `installers/R110_install.lua` (built against the live R107 scripts + R109 pack fix).

## Install (Studio, Edit mode, Play stopped)

1. Open `installers/R110_install.lua`, copy **all** of it, paste into the Command Bar, press Enter.
   It checks every script first and refuses (changing nothing) if any script is not the expected version.
2. Output should end with `[R110] Installed.` and a backup line.
3. **Save**, then start a **new** Play session.

Undo: `require(game.ServerStorage.ChestChase_R110_TutorialHudMovement_Backup.Installer)("undo")`, then save.
Redo later: same line with `"install"`. Undo refuses if you hand-edited one of the scripts after installing.

## Test in Studio (things only Studio can show)

To see the tutorial with an existing save: **Settings -> Replay tutorial**.

- [ ] Welcome pop-up appears after the title screen; "LET'S GO!" closes it.
- [ ] Red arrows start under your feet and lead to a Forest pack; they follow paths around walls; a "STEAL!" marker bounces over it.
- [ ] Card at the top: steps advance as you steal, run back, open, plant, wait, harvest, sell, collect, treadmill.
- [ ] Step 3 arrow points at the pack in your hotbar.
- [ ] Phone emulator (e.g. iPhone 14 landscape and portrait): card, menu wheel, hotbar and joystick don't overlap.
- [ ] Run full speed into the lobby wall, the track end and plants: you stay upright.
- [ ] Get hit by a keeper / bat: you still ragdoll and get up normally.
- [ ] Watch keepers chase, strike, return to camp: smooth, no stepping.
- [ ] Another player (second Studio client) does **not** see your arrows.

## How it was checked (outside Studio)

- Tutorial script run in a mocked Roblox runtime with the real Luau interpreter: 950 checks (all steps, welcome, replay, skip, finish, device wording, menu hiding, cleanup).
- Card and HUD placement: no overlaps on 26 PC/phone/tablet screen sizes, with and without touch controls.
- Runner fix: 11 scenario groups against mocks (trips recovered; knockback, fling, treadmill, seats, climbing, swimming, flight, death untouched).
- Keeper smoothing: simulated 25-1000 studs/s at 20/30/60 Hz and 30/60/144 FPS: jitter 13-250% -> 10-20% RMS, lag about halved.
- All 9 scripts compile and type-check against the Roblox API (luau-lsp); installer tested end to end (install, re-paste, undo, redo, refusals, rollback).
- Not checked: anything visual in Studio, real physics, real networking.

## Known follow-ups

- Invisible map barriers are collidable but `CanQuery=false`, so the runner's wall sweep can't see them (the new trip guard covers the symptom). Setting them `CanQuery=true` may affect the camera; test before changing.
- If a keeper stops mid-strike it can overshoot by up to one network update of travel, then eases back.
