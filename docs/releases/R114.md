# R114: bug fixes (pictures, BASE/TRACK in the top middle, "All" card)

Needs R113 installed first (refuses otherwise, changing nothing). Installer: `installers/R114_install.lua` (~25 KB).
Edit mode, Play stopped, paste ALL of it into the Command Bar, Enter, then **Save** and start a **new** Play session.

Undo: `require(game.ServerStorage.ChestChase_R114_Backup.Installer)("undo")` (undo R114 before R113).

## What changed (5 scripts)

- **Pictures back:** packs/seeds/fruit showed flat icons because the automatic frame-rate saver (it kicks in when FPS
  drops, which happens a lot in Studio) switched pictures off. Now only the player's own **Settings -> Quality -> Low**
  gives flat icons (`ItemPictures`, `SettingsClient`).
- **BASE / TRACK:** wide rectangles centred in the top row next to Roblox's own buttons; they shrink to fit phones
  and hide only on the title screen and full-screen menus (`TravelButtons`).
- **Inventory cards:** "All"/"Seeds"/"Fruit"/"Tools" never stick out above the inventory any more. On the smallest
  phones the whole inventory moves up a little instead (`Hotbar`).
- `Config.Version = 'V149 R114'`.
