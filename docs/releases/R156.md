# R156: weather ambience (rain, thunderstorm, blizzard)

Needs **R155 installed** (both parts; `Config.Version` reads `'V150 R155'`). **One installer:** `installers/R156_install.lua` (~36 KB, 2 scripts).
Edit mode, Play stopped, **close every script tab first**, paste ALL of it into the Command Bar, Enter, wait for **`[R156] Installed.`**, then **Save**
and start a **new** Play session. `Config.Version` reads `'V150 R156'` after it.

- It refuses if R155 isn't in ("Config is not the version this update was built for. Nothing changed."): paste R155 part 1 and part 2 first.
- `BackgroundMusic` is not touched (the base / track music change comes in a later update). Nothing is retired.

Undo: `require(game.ServerStorage.ChestChase_R156_Backup.Installer)("undo")`.

## Before you publish
1. Shut Down All Servers after publishing (or Migrate To Latest Update). Nothing breaks if R155 and R156 servers run side by side; the R155 servers just
   have no weather ambience.
2. **The three sounds must be usable by this game.** U uploaded them yourself, so if the game is yours they just work. If the game belongs to a group,
   open each sound on the Creator Dashboard and give the experience permission. A sound the game may not use stays silent, and the Output says
   `[R73] WeatherRainAmbience unavailable; check its experience audio permissions` (or `WeatherThunderAmbience` / `WeatherBlizzardAmbience`).

Profile version stays 22 (no saved-data change).

## What changed
| Weather | Plays | Sound |
|---|---|---|
| Rain | the rain ambience | 107960597100236 |
| Thunderstorm | the thunderstorm ambience | 137593145026034 |
| Blizzard | the blizzard ambience | 87749574738390 |
| Sunny (Clear), Cloudy | the same as now (birds, leaves) | |

- Only the current weather's ambience plays, never two at once. It fades in when the weather starts and fades out when it ends. Rain turning into a
  thunderstorm crossfades.
- **In the base and hub only:** the track has no weather, so it's quiet there. Walking onto the track fades the ambience out; coming back fades it in.
- It's on the **Ambience** slider in Settings, and it goes almost silent during a chase like the other ambience.
- The thunder claps and rumbles u already have stay as they are, on top.
- Volumes: rain 0.30, thunderstorm 0.32, blizzard 0.30 (before the Ambience slider). Tell me "louder" or "quieter" and I change the number.
