# R156: weather ambience (rain, thunderstorm, blizzard), new track and base music, the item info panel removed

Needs **R155 installed** (both parts; `Config.Version` reads `'V150 R155'`). **One installer:** `installers/R156_install.lua` (~51 KB, 6 scripts
+ moves 1 unused module into the backup). Edit mode, Play stopped, **close every script tab first**, paste ALL of it into the Command Bar, Enter, wait
for **`[R156] Installed.`**, then **Save** and start a **new** Play session. `Config.Version` reads `'V150 R156'` after it.

- It refuses if R155 isn't in ("Config is not the version this update was built for. Nothing changed."): paste R155 part 1 and part 2 first.
- It **moves** (never deletes) `ReplicatedStorage.ItemTooltip155` (the item info panel) into `ServerStorage.ChestChase_R156_Backup`. Undo puts it back.
- `BackgroundMusic` IS changed this time (u asked for the new music).

Undo: `require(game.ServerStorage.ChestChase_R156_Backup.Installer)("undo")`.

## Before you publish
1. Shut Down All Servers after publishing (or Migrate To Latest Update). Nothing breaks if R155 and R156 servers run side by side.
2. **Every new sound must be usable by this game.** The base tracks (1837487700, 1837487818, 1836280952) are from Roblox's library, so they work in
   any game. Ur own uploads (the 3 ambiences, 74095461107598, 132448918728086) just work if the game is yours. If it belongs to a group, open each on
   the Creator Dashboard and give the experience permission. A sound the game can't use stays silent and the Output says so:
   `[R73] WeatherRainAmbience unavailable ...` for an ambience, `[V123 FIX1] Music not ready: ...` for a music track. A track that fails is skipped
   and the others keep playing.

Profile version stays 22 (no saved-data change).

## What changed
### Weather ambience
| Weather | Plays | Sound |
|---|---|---|
| Rain | the rain ambience | 107960597100236 |
| Thunderstorm | the thunderstorm ambience | 137593145026034 |
| Blizzard | the blizzard ambience | 87749574738390 |
| Sunny (Clear), Cloudy | the same as now (birds, leaves) | |

- Only the current weather's ambience plays, never two at once. It fades in when the weather starts and out when it ends; rain turning into a
  thunderstorm crossfades.
- **In the base and hub only:** the track has no weather, so it's quiet there. Walking onto the track fades it out; coming back fades it in.
- On the **Ambience** slider in Settings, and it drops right down during a chase like the other ambience. The thunder claps stay as they are, on top.
- Volumes: rain 0.30, thunderstorm 0.32, blizzard 0.30. Tell me "louder" or "quieter" and I change the number.

### Music
- **Track:** "Nature Inspiration" (the track music u had), then **74095461107598**, then **132448918728086**, then back to the start. Each plays to its
  end and crossfades (3 s) into the next. A bit louder than before (0.055 -> 0.07). Leaving the track fades it out; coming back picks up the same song
  where it was. Chases take over exactly as before.
- **Track ambience** (wind, birds, the crystal hum, the rumble on the track) about 25% louder. The base ambience is unchanged.
- **Base:** **1837487700, 1837487818, 1836280952** join Morning Mood and Clair de Lune in the base shuffle (5 songs). Base volume unchanged.

### Item info panel removed
- The dark info panel (a pack's odds, the pity rule, a seed's "Click or tap the soil to plant!") no longer shows on hover, tap-hold or gamepad.
- The Mech packs' odds and coat chances are still on the shop card before buying (what Roblox requires for paid random items).
- The Bag's hint no longer says "hover for info" (the whole hint line goes in the Bag look update).
