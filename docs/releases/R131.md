# R131: gifting fixed, gift notice with sound, smaller name bubbles, rarer weather mutations

Needs R130 installed first (refuses otherwise, changing nothing). Installer: `installers/R131_install.lua` (~36 KB, 8 scripts).
Edit mode, Play stopped, paste ALL of it into the Command Bar, Enter.
**Wait for `[R131] Installed.`** before pressing Play, then **Save** and start a **new** Play session.

Undo: `require(game.ServerStorage.ChestChase_R131_Backup.Installer)("undo")`.

## What changed

**Gifting fixed**
- **Why it did nothing in Studio:** Studio's test players (Player1, Player2…) have negative account ids, and the server threw away every gift to an id below 1, without a message. Studio test ids are accepted now; live servers are unchanged (real ids are always positive).
- **No more silent failures.** The giver is told why a gift can't happen:
  - "Gifts need saving: turn on Studio API access (Game Settings > Security) and test again." (Studio without saving)
  - "Bob's save is not ready, so they can't receive gifts."
  - "Bob is in a run right now." / "Finish your run first."
  - "Something is between you and Bob. Move to where you can see them." / "Get closer to Bob to give."
- **No waiting on a busy save:** if a gift save or inbox check is still running for either player, the gift waits a few seconds and goes through instead of being refused.
- **Faster delivery:** a gift that arrived while the receiver's inbox was being checked was picked up up to 60 s later; now it's picked up right after. Inbox reads also skip Roblox's 4-second read cache.

**Receiving a gift**
- The receiver gets a gold notice at the top, **"🎁 Sunny gave you Frosted Golden Apple!"**, with a reward chime (the same chime as Index claims).

**Garden name bubbles**
- The badge above each garden (avatar + name) was a fixed 210 × 128 px drawn on top of everything, so from a distance it covered gardens.
- Now it is sized in studs with a small minimum, so it shrinks with distance like the garden under it, and gardens or buildings in front of it hide it.

  | Distance | Before | After |
  |---|---|---|
  | 40 studs | 210 × 128 px | 175 × 111 px |
  | 100 studs | 210 × 128 px | 90 × 57 px |
  | 200 studs | 210 × 128 px | 62 × 39 px |
  | 400 studs | 210 × 128 px | 48 × 30 px |

- With no avatar picture (Studio test players), only the name shows, not a blank circle.
- Badges already in your place are restyled automatically.

**Weather mutations: 0.2% per minute**
- During rain, thunderstorms and blizzards, every exposed pack, plant and fruit gets one 0.2% roll per minute (was one 2% roll per event). A 3-minute event is about 0.6% per object.
- `weather <kind> all` still forces every mutation for testing.

`Config.Version = 'V150 R131'`.

## Test in Studio (Test > Clients and Servers, 2 players)
- **Gifts:** hold fruit, a seed and a pack, click Player2, press Give. Player2 gets the gold notice and the chime. If Studio API access is off, Player1 is told so.
- **Name bubbles:** look across the base at other gardens. The badges are smaller from far away and don't cover the gardens.
- **Weather:** `weather rain` then wait. Mutations are rare now; `weather rain all` still forces them.
