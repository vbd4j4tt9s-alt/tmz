# R116: value order fix, cash/gem number jump, text-only BASE/TRACK with highlight

Needs R115 installed first (refuses otherwise, changing nothing). Installer: `installers/R116_install.lua` (~27 KB).
Edit mode, Play stopped, paste ALL of it into the Command Bar, Enter, then **Save** and start a **new** Play session.

Undo: `require(game.ServerStorage.ChestChase_R116_Backup.Installer)("undo")` (undo R116 before R115).

## What changed (4 scripts)

- **Sell values follow one rule** (`ReplicatedStorage.EconomyBalance90`, `FruitValues`):
  - A plant's income = biome base x tier: Common 1, Uncommon 1.6, Rare 2.5, Legendary 4, Mythic 7, Secret 20,
    Cosmic 60, King 500. Single-harvest plants pay 10 minutes of that income once.
  - So a higher tier always earns more than a lower tier in the same biome (0 exceptions, checked on all 51 plants), and
    a later biome always beats the same tier in an earlier biome.
  - Each biome's base keeps an average pack worth what it was before, so **shop prices did not change**.
  - Dune Lotus pays 52M once (was 180M), valued as Desert's Rare. Desert's other plants went up to make up for it.
  - Kings are now the best plant in every biome. Examples: Pulsar Starfruit 2.5B -> 39.9B a fruit, Ember Emperor 400M -> 5.45B.
    The paid Mech King (Crowncore) is 29.3B, below the Storm King.
  - Lava Lotus 900M -> 330M and Aurora Lily 270M -> 145M (they used to out-pay Secrets).
  - Index cash per plant scales with its new value, as before. Harvested fruit already in bags keeps its saved price.
- **Cash and gems jump** when they go up, like speed (not while your save first loads).
- **BASE / TRACK:** pictures removed, bigger centred text, brighter glossy highlight, drop shadow, bounce on hover/press.
- `Config.Version = 'V149 R116'`.
