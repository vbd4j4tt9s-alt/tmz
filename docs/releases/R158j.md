Needs **R158i installed** (`Config.Version` reads `'V150 R158i'`). **One installer:** `installers/R158j_install.lua` (~37 KB, 3 scripts).

then **Save** and start a **new** Play session. `Config.Version` reads `'V150 R158j'` after it.

  | Lava | 128 / 147 / 166 | 128.1 / 147.0 / 166.0 |
  | Crystal, Storm Peaks | (no change: 20,000 speed is nothing at their level) | |
